# GeoTrail — ტურისტული ვებგვერდი

რესპონსიული ვებგვერდი საქართველოს პოპულარული ტურისტული მიმართულებებით, მოგზაურთა შეფასებებით და დაჯავშნის ფორმით.
შექმნილია **HTML5, CSS3 (Flexbox + Grid)** და **ვანილა JavaScript**-ით, ფრეიმვორკების გარეშე.

![Desktop](docs/screenshots/desktop.png)

## ✨ ფუნქციონალი
| კომპონენტი | აღწერა |
|-----------|--------|
| ნავიგაცია | Sticky ჰედერი, მობილურზე ჰამბურგერ-მენიუ (`aria-expanded`, `Esc`-ით დახურვა) |
| ფილტრი | მიმართულებების გაფილტვრა კატეგორიით (მთა / კულტურა / ზღვა) |
| სლაიდერი | შეფასებების კარუსელი: ისრები, წერტილები, კლავიატურა, ავტომატური გადასვლა |
| ფორმა | ვალიდაცია რეალურ დროში, შეცდომის შეტყობინებები, წარმატების შეტყობინება |
| ღილაკი „ზემოთ“ | ჩნდება სქროლისას (`requestAnimationFrame` throttling) |

```
geotrail/
├── index.html          # სემანტიკური HTML5 გვერდი
├── css/style.css       # სტილები, Flexbox/Grid, media queries
├── js/main.js          # ინტერაქტიულობა (5 დამოუკიდებელი მოდული)

├── docs/
│   ├── work-plan.md    # სამუშაო გეგმა, რისკები, რესურსები

└── README.md
```

## 🧱 HTML5 სემანტიკა
`header`, `nav`, `main`, `section` (თითო `aria-labelledby`-ით), `article`, `figure/figcaption`, `blockquote`, `address`, `footer`; ერთი `h1`, იერარქიული `h2/h3`; `skip-link`; `lang="ka"`.

## 🎨 CSS და რესპონსივობა
- **CSS Custom Properties** ფერებისა და ზომებისთვის
- **Flexbox:** ჰედერი, ფილტრები, სლაიდერის კონტროლები, ფუტერი
- **Grid:** ბარათები (1 → 2 → 3 სვეტი), უპირატესობების ბლოკი, ფორმის ველები
- **Mobile-first breakpoints:** 640px, 768px (პლანშეტი), 1024px (დესკტოპი)
- `prefers-reduced-motion` მხარდაჭერა

## ⚡ ოპტიმიზაცია
- სკრიპტი `defer`-ით, ბლოკირების გარეშე
- სურათები SVG ფორმატში (რამდენიმე KB), `loading="lazy"`, `width/height` ატრიბუტები (CLS-ის თავიდან ასაცილებლად)
- Hero სურათის `preload`
- Inline favicon — დამატებითი მოთხოვნის გარეშე
- გარე ბიბლიოთეკების/ფრეიმვორკების გარეშე (0 დამოკიდებულება)
- ერთი CSS და ერთი JS ფაილი → მინიმალური HTTP მოთხოვნები
- წვდომადობა: ARIA ატრიბუტები, ფოკუსის სტილები, კონტრასტი

## 🚀 გაშვება
```bash
cd geotrail
# უბრალოდ გახსენით index.html ბრაუზერში, ან:
python3 -m http.server 8000   # შემდეგ http://localhost:8000
```
